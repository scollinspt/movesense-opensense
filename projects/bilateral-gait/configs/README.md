# Bilateral gait configurations

Store versioned, non-sensitive acquisition and protocol configurations here.

Each configuration must identify:

- Project and protocol version.
- Enabled environment and task scope.
- Number of sensors and anatomical roles.
- Placement and orientation confirmations.
- Sensor resource routes and requested rates.
- Required calibration and gait events.
- Structured context options.
- Output schema versions.

Do not store participant identifiers, recordings, credentials, private device
inventories, or host-specific paths.

  protocol with straight and turning path segments.
